# P62 — План слияния веток и сводный план реализации

Версия: v1.0
Статус: ready

## 1) Цель
- Надёжно объединить две проектные ветки (далее: BRANCH_A, BRANCH_B) без потери функциональности и документов, с чёткими чекпойнтами возобновления.
- Зафиксировать эталонный план реализации P62 после слияния.

## 2) Предварительные условия
- Обе ветки синхронизированы с origin; все локальные изменения закоммичены.
- Смоки на текущих ветках зелёные (минимум: `/api/health`, `/api/routes`, `/openapi.json`).
- Среда: Python/Node версии зафиксированы; requirements.txt актуален.

## 3) Процедура слияния (git)
1. Обозначить ветки:
   - BRANCH_A = p62-visual-hr (рекомендация)
   - BRANCH_B = <вторая ветка>
2. Подготовка:
   - `git checkout BRANCH_A && git pull --ff-only`
   - `git checkout BRANCH_B && git pull --ff-only`
3. Базовая интеграция:
   - `git checkout BRANCH_A`
   - `git merge --no-ff BRANCH_B`
   - Разрешить конфликты: предпочитать контракты/ТЗ из `docs/P62_OPENAPI_SPEC_v1.yaml`, `Soul/P62_TZ_...`, затем код.
   - Соблюдать правила безопасности (RBAC/Two-Keys, P27, отсутствие хардкодов URL/секретов).
4. Смоки после merge:
   - `./scripts/p62_smoke.sh` или `./scripts/p62_smoke.ps1`
   - `pytest -q tests/test_p62_*`
5. Фиксация:
   - Коммит объединения с сообщением: "merge: BRANCH_B into BRANCH_A (P62 baseline)"
   - Тег: `git tag p62-merge-baseline`

## 4) Разрешение конфликтов — приоритеты
- Истина — в документах: `docs/P62_OPENAPI_SPEC_v1.yaml` и `Soul/P62_TZ_...`.
- Не нарушать P27/Two-Keys/RBAC.
- UI: придерживаться enterprise‑стиля (без «игровых» элементов).
- WS: общие топики из P62; новые — только через доп. флаги.

## 5) Пост-слияние — фазы реализации (выдержка)
- Следовать `docs/P62_DEVELOPER_ROADMAP.md` (фазы -1..7).
- Сразу установить чекпойнт: `FLAGS.SET state.p62.phase=-1`.

## 6) Контроль качества
- Смоки (curl/CLI), pytest (контракты/JSON/WS/YAML), инспекторы DSL.
- Отчёты сохранять в `out/`.

## 7) Роллбек
- На коммите с тегом `p62-merge-baseline`: при критическом регрессе — revert merge; затем точечная интеграция.
