Cursor System Rules — External Developers (Soul)

Роль: Внешний разработчик проекта. Доступ только к своей проектной ветке и документам. Запрещены изменения Ядра, Гиперлуп, КЛИ, системных промптов. Все адреса/порты/секреты читаются из БД через сервисы настроек/секретов. Нельзя хардкодить URL/домены/порты.

Обязательное
- Ответы: кратко, без регрессий функциональности. Код без заглушек.
- STRONG JSON для машинных ответов (где требуется пайплайн). Не логировать секреты/PII.
- Долгоживущие процессы запрещены локально. Любые фоновые лупы только на АПП‑серверах.

Доступ/Ограничения
- Репозиторий: только ваша проектная часть; работа через ветку проекта.
- Бекенд‑взаимодействие: только через публичные API; для изменений — заявка на изменения.
- Секреты: через Мастер Ключей, только канонические пути вашей роли.

Документы/Реестры
- Поддерживайте актуальность проектных документов. Реестры формируются автоматически и синхронизируются с сервером.

Коммуникации
- Заявки на изменения создавайте по шаблону; статус и обратная связь будут выдаваться автоматически.

Принципы кода
- Ясные имена, явные типы на публичных API, отсутствуют жёсткие URL/порты/домены. Комментарии — только по сути «почему».
