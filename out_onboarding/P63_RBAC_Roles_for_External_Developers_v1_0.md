RBAC — Роли и полномочия для внешних разработчиков (P63)

1. Общие принципы
- Минимально‑необходимые права (least privilege), доступ только к проектной ветке и артефактам проекта.
- Доступ к Мастеру Ключей: только канонические пути роли; запись своих секретов; чтение строго по необходимости.
- Любые изменения API/логики/коннекторов — только через Заявку на изменение (CR).

2. Роли (ключи)
- ext_frontend_dev — Внешний разработчик фронтенда Соул
- ext_integration_dev — Внешний разработчик смежной интеграции
- ext_channel_dev — Внешний разработчик эфемерного канала/агента
- ext_soulpulse_dev — Внешний разработчик SoulPulse

3. Политики
- Права (минимум): чтение ключевых данных и промптов, модели/функции LLM, профиль self.
- Key Master:
  - Разрешена запись только `dev.*` и собственного `bot.token.<tg_id>`.
  - Архитектор/Админ — полный доступ.
- ONBOARDING.* — только `soul.admin` (Внешние роли не исполняют напрямую).
- PDP/Аудит: все действия подписаны P27, нарушение — инциденты.
